\# Link Ride



Link Ride is a multimodal public transport prototype designed to provide commuters with a unified journey-planning experience across formal and informal transport services in South Africa.



The prototype demonstrates a federated interoperability approach by combining multiple transport providers behind a common backend and presenting journey planning, payments, ticketing, disruptions, notifications and user preferences through a single Flutter mobile application.
